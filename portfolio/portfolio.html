The Project

What I Built

I built a neighborhood-level market intelligence system using residential MLS data from Kyle, Texas.

The project takes raw housing data through cleaning, processing and analysis, then turns it into Power BI reporting and public-facing market reports.

The goal wasn't just to build dashboards.

The goal was to create a repeatable system that turns raw property data into useful market information for buyers, homeowners and real-estate decision making.
